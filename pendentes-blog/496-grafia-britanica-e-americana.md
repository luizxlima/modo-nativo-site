"Color" ou "colour"? "Organize" ou "organise"? As duas estão certas, e a escolha depende do padrão que você adota. O erro não é escolher um ou outro: é misturar os dois no mesmo texto, o que sinaliza falta de atenção. Neste artigo você vai ver as seis regras que explicam quase todas as diferenças de grafia, com tabela de referência e orientação sobre qual padrão usar.

## Grafia britânica e americana: as seis regras

### Regra 1: -or contra -our

Palavras terminadas em -our no britânico perdem o U no americano.

| Americano | Britânico |
| --- | --- |
| color | colour |
| favor | favour |
| honor | honour |
| labor | labour |
| behavior | behaviour |
| neighbor | neighbour |
| flavor | flavour |
| humor | humour |

### Regra 2: -ize contra -ise

Verbos terminados em -ize no americano podem aparecer como -ise no britânico.

| Americano | Britânico |
| --- | --- |
| organize | organise |
| realize | realise |
| recognize | recognise |
| apologize | apologise |
| analyze | analyse |
| summarize | summarise |

Detalhe importante: **-ize é aceito também no Reino Unido** e é a forma preferida pelo dicionário Oxford. Já **-ise é obrigatório no britânico** em algumas palavras, como "advertise", "surprise" e "exercise", que nunca levam Z.

E "analyze" tem o par britânico "analyse", com S, o que é diferente do padrão -ize.

### Regra 3: -er contra -re

| Americano | Britânico |
| --- | --- |
| center | centre |
| theater | theatre |
| meter | metre |
| liter | litre |
| fiber | fibre |

### Regra 4: -se contra -ce

| Americano | Britânico |
| --- | --- |
| defense | defence |
| offense | offence |
| license (subst. e verbo) | licence (subst.), license (verbo) |
| practice (subst. e verbo) | practice (subst.), practise (verbo) |

### Regra 5: consoante dobrada

No britânico, o L dobra ao receber sufixo; no americano, não.

| Americano | Britânico |
| --- | --- |
| traveling | travelling |
| traveled | travelled |
| canceled | cancelled |
| modeling | modelling |
| labeled | labelled |

Note: "canceled" com um L é americano, mas "cancellation" leva dois L nos dois padrões.

### Regra 6: palavras avulsas

| Americano | Britânico |
| --- | --- |
| program | programme (exceto software) |
| catalog | catalogue |
| dialog | dialogue |
| check | cheque (bancário) |
| gray | grey |
| tire | tyre (pneu) |
| aluminum | aluminium |
| jewelry | jewellery |
| aging | ageing |
| judgment | judgement |

"Program" é curioso: mesmo no Reino Unido, o programa de computador é "program"; só o programa de TV e o de curso são "programme".

## Qual padrão usar

Depende do público:

- **Empresa americana ou público global de tecnologia**: use o americano. É o padrão dominante em documentação técnica.
- **Reino Unido, Irlanda, Austrália, Nova Zelândia, África do Sul**: use o britânico.
- **União Europeia e organismos internacionais**: geralmente britânico.
- **Canadá**: mistura, com tendência ao britânico em -our e ao americano em -ize.

Se você não sabe, escolha o americano: é o mais usado globalmente e ninguém vai considerar errado.

## A regra que importa mais que a escolha

**Consistência.** Um texto com "colour" e "organize" misturados chama mais atenção que qualquer uma das duas escolhas sozinha.

Como garantir:

1. Configure o corretor do seu editor para o padrão escolhido (English US ou English UK).
2. Em documento compartilhado, verifique qual padrão os outros usaram antes de editar.
3. Em currículo, use o padrão do país da vaga.

## As palavras que não mudam

Para tranquilizar: a maioria das palavras é idêntica nos dois padrões. As diferenças se concentram em alguns grupos previsíveis, e a lista completa cabe em uma página. Não é um idioma diferente, é uma convenção de escrita.

## Além da grafia: pontuação e datas

Duas diferenças que passam despercebidas:

- **Aspas**: o americano usa aspas duplas como padrão; o britânico usa simples em alguns estilos.
- **Ponto nas abreviações**: americano escreve "Mr." e "Dr." com ponto; britânico escreve "Mr" e "Dr" sem.
- **Datas**: americano usa mês/dia/ano (11/24/2026); britânico usa dia/mês/ano (24/11/2026).

A diferença de data é a que causa problema real em agenda e contrato. Para evitar ambiguidade, escreva o mês por extenso: "24 November 2026" ou "November 24, 2026".

## Mini teste rápido

Qual é a grafia britânica?

1. Color
2. Organize
3. Center
4. Traveling
5. Catalog

Respostas: 1. Colour. 2. Organise (ou organize, aceito). 3. Centre. 4. Travelling. 5. Catalogue.

## Conclusão: escolha um padrão e não misture

Seis regras explicam quase todas as diferenças: -our, -ise, -re, -ce, L dobrado e algumas palavras avulsas. A escolha importa menos que a consistência, e o corretor do editor resolve o resto.
